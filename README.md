# TripBook – Mi diario de viajes

## Descripción

TripBook es una aplicación web que permite registrar, organizar y conservar experiencias de viaje mediante un diario digital personal.

## Objetivo

Crear un espacio donde los usuarios puedan guardar fotografías, descripciones, fechas y calificaciones de sus destinos turísticos.

## Funcionalidades

- Registrar viajes.
- Subir fotografías desde el dispositivo.
- Visualizar recuerdos mediante tarjetas.
- Consultar detalles de cada viaje.
- Editar y eliminar registros.
- Buscar viajes por nombre, país y ciudad.
- Filtrar por categorías.
- Ordenar por fecha.
- Conservar información mediante SQLite y localStorage.

## Instalación

```bash

```

## Ejecutar en desarrollo

```bash
npm run dev
```

## Compilar

```bash
npm run build
```

## Vista previa de producción

```bash
npm run preview
```

## Base de datos

TripBook utiliza SQL.js para ejecutar SQLite en el navegador. La base de datos se serializa y se almacena en localStorage para conservar los registros en el mismo navegador y dispositivo.

## Despliegue en Vercel

1. Subir el proyecto a un repositorio de GitHub.
2. Importar el repositorio desde Vercel.
3. Seleccionar Vite como framework.
4. Utilizar `npm run build` como comando de compilación.
5. Configurar `dist` como directorio de salida.
6. Desplegar el proyecto.
